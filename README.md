# New project

## How to initialize the new project?
1. `$ mkdir new-project`
1. `$ cd new-project`
1. `$ git init`
1. `$ touch README.md`
1. `$ git add README.md`
1. `$ git commit -m "init"`

## How to develop features separately from the ***main*** branch?
Simply switch to ***development*** branch (it's already created in the repo):
```bash
$ git checkout development
```
And have fun :wink:
